## 📖 Description

Manhattan is a responsive landing page designed for a music club and bar. The website presents the venue, food and drinks menu, upcoming live performances, photo gallery, and additional information through a modern interface with smooth navigation and interactive components.

---

## ✨ Key Features

- Fully responsive layout.
- Food and drinks menu section.
- Upcoming events and live performances.
- Interactive photo gallery.
- Content slider.
- Smooth page navigation.
- Modern dark-themed interface.

---

## 🛠 Development

- Semantic HTML5 markup.
- Modular SCSS architecture.
- Custom Gulp build workflow.
- Responsive layout using Flexbox.
- Cross-browser compatibility.
- Optimized project structure.
- Performance-oriented implementation.

---

## 🎯 Result

The final product is a modern and responsive landing page that effectively promotes the music club, showcases its events and menu, and provides visitors with an engaging browsing experience across all devices.
